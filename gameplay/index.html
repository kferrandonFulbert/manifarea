Gameplay Manifarea :
comment jouer ?

Manifarea est un jeu de simulation de manifestation situé à Chartres. Voici les commandes affichées sur le site du jeu pour te déplacer, consulter les règles et utiliser les actions prévues par le gameplay.

Lancer Manifarea ↗

Les commandes du jeu

Les touches suivantes sont celles indiquées sur la page de Manifarea au moment de la rédaction. Le jeu peut évoluer : si une commande diffère, fie-toi en priorité aux indications affichées dans le jeu et à son écran de règles.

  • ZQSD ou les flèches : se déplacer.
  • Espace : action « casser » pour les manifestants.
  • E : frapper.
  • V : afficher la vue d’ensemble.
  • H : consulter les règles.
  • M : activer ou couper le son.
  • Entrée : ouvrir ou utiliser le chat.

Comment commencer une partie ?

  1. Ouvre le site de Manifarea.
  2. Consulte les règles avec la touche H pour comprendre le fonctionnement et les actions disponibles.
  3. Utilise ZQSD ou les flèches pour te déplacer ; appuie sur V pour obtenir une vue d’ensemble.
  4. Utilise le chat avec Entrée si tu souhaites communiquer avec les autres joueurs.

Les informations disponibles ne détaillent pas ici la procédure de choix d’un camp, les conditions de victoire ou la durée des parties. Ces éléments ne sont donc pas supposés : vérifie les règles intégrées au jeu.

Des commandes de jeu, pas des conseils dans la rue

Manifarea met en scène une simulation vidéoludique. Les actions affichées, y compris « casser » ou « frapper », appartiennent au gameplay fictif et ne sont pas des recommandations à reproduire dans la vie réelle. Pour les risques juridiques liés aux dégradations, consulte notre page Jouer plutôt que casser.
