État des vérifications

Cheatcodes
Manifarea

Tu cherches un code secret ? Mieux vaut une réponse honnête qu’une liste sortie d’un képi magique.

Aucun code vérifié par ce blog à ce jour.

Cela ne signifie pas qu’il n’en existe pas dans le jeu. Aucun code n’est publié ici tant qu’une source fiable, la version concernée, la procédure et l’effet observé n’ont pas été établis.

Comment un code sera documenté

Avant publication, chaque entrée devra préciser :

  • le code exact et sa source ;
  • la version du jeu et le mode compatible, s’ils sont connus ;
  • la procédure et l’effet effectivement observé ;
  • la date de vérification et les limites éventuelles.

Pas de raccourci contre les autres joueurs

Cette rubrique ne proposera ni exploitation du serveur, ni contournement anti-triche, ni méthode donnant un avantage non autorisé en multijoueur. Les commandes de développement, si elles sont documentées, seront identifiées comme telles.

Les informations et les canaux officiels du jeu ne nous ont pas encore été communiqués. Aucun lien externe n’est ajouté tant qu’il n’a pas été vérifié.
